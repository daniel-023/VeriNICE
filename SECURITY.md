# Security policy

VeriNICE is designed to run locally. The deployed walkthrough contains recorded
results and does not expose the model-backed FastAPI service.

Please report suspected vulnerabilities privately through GitHub's **Report a
vulnerability** feature. Do not include credentials, private source documents,
or personal data in a public issue.

Only the latest commit on the default branch receives security fixes. Before
reporting a dependency advisory, confirm that it still affects the versions in
the lockfiles.
