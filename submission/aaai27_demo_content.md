# VeriGraph: Inspectable Claim Verification from Evidence Spans to Verdict Rules

**Anonymous demonstration submission — content draft**

## Abstract

Fact-verification systems often return a label while hiding the intermediate
decisions that made the label possible. VeriGraph is an interactive
demonstration that turns a complex claim into typed verification obligations,
retrieves source-grounded evidence for each obligation, classifies
sentence-level support and contradiction, and assembles the results into an
argument graph with a deterministic four-way verdict. Visitors can move from a
verdict to the rule that produced it, then to an obligation, a model relation,
and the exact source passage. The system combines local language-model
decomposition, hybrid dense/lexical retrieval, conservative natural-language
inference, linguistic auditing, and symbolic aggregation. A searchable case
browser supports topic, verification-challenge, and reference-verdict filters;
custom claims and documents can run locally. A recorded walkthrough preserves
the same typed intermediates as an offline fallback. The demonstration's main
contribution is an inspectable bridge between statistical components and
rule-governed decisions, not another opaque factuality score.

## Motivation and significance

A single fact-checking label compresses several distinct questions: Was the
claim decomposed faithfully? Did retrieval miss a decisive passage? Did an NLI
model over-read contradiction? Did the final rule respect conjunction,
alternatives, and mixed evidence? These questions matter even when the final
label is correct. They are difficult to ask when intermediate results are
discarded or shown as unconnected tables.

VeriGraph makes the chain itself the interface. Every obligation retains exact
grounding in the original claim. Every evidence candidate retains document and
sentence offsets. Support and attack edges are derived from stored NLI
relations. The final SUPPORTED, REFUTED, NOT_ENOUGH_EVIDENCE, or
CONFLICTING_EVIDENCE decision is generated by a deterministic,
composition-aware rule and displayed with its trace. Dataset reference labels
are visible only as metadata and never enter inference.

## System

The user selects a curated AVeriTeC case or enters a claim with source
documents. A local Qwen2.5 model proposes a schema-constrained, contextualized
decomposition of at most twelve standalone obligations. Each obligation has a
verification role and exact UTF-16 source grounding. Invalid output receives
one repair attempt; failure preserves the full claim as one obligation so the
rest of the pipeline remains usable.

Retrieval segments documents and combines BGE dense similarity with lexical
anchors using reciprocal-rank fusion. Exact numbers and names can therefore
recover passages that semantic similarity alone ranks poorly. Soft source
diversity avoids forcing irrelevant passages into a multi-document result.

A DeBERTa model classifies each obligation/passage pair. The system defaults to
neutral when a non-neutral prediction is weak. Contradiction additionally
requires an inspectable anchor such as negation, incompatible numbers,
opposing terms, or a matched entity-set mismatch. These gates trade recall for
a more defensible live demonstration.

The frontend builds a typed argument graph from the stored decomposition and
NLI outputs. A backend rule engine then aggregates obligation states according
to SINGLE, AND, or OR composition. A spaCy sidecar audits entities, qualifiers,
negation, modality, and role preservation. Its warnings are deliberately
verdict-neutral.

## Demonstration experience

The opening view offers human-titled cases with free-text search and filters
for topic, challenge, and reference verdict. A visitor might choose a case with
numerical conflict, cross-source disagreement, or insufficient evidence. The
presenter runs the five stages, opens one obligation, follows its highlighted
candidate into the full source, and then follows the same obligation into the
argument graph and verdict trace. The visitor is invited to challenge a
specific step rather than accept or reject the system wholesale.

The live system runs locally to avoid dependence on conference connectivity.
The backup mode is a static interactive walkthrough containing the same typed
intermediates from recorded local runs. The private catalog has 32 cases,
balanced at eight per reference label, while the checked-in walkthrough has 22
recorded model runs. We will claim a 32-run evaluation only after the ten added
cases are recorded and audited.

## Evaluation and limitations

The evaluation report separates verdict agreement from decomposition quality
and error source. Current deterministic decomposition diagnostics cover
atomicity, coverage, sufficiency, non-fabrication, non-redundancy, readability,
and linguistic warnings. They are engineering proxies, not human judgments or
the FactLens evaluator. The current 22-run snapshot has 10/22 reference-verdict
agreement (45.5%), so accuracy is not presented as a contribution. Before final
submission we will complete error attribution, a small human decomposition
audit, and the balanced 32-case rerun.

VeriGraph verifies supplied documents; it does not establish source authority
or perform open-web fact checking. Retrieval rank is not truth, NLI neutral is
not a case-level insufficient-evidence label, and the graph does not infer new
relations. These boundaries are stated in the interface and demo narration.

## Related work

WiCE introduced real-world entailment with subclaim-oriented verification in
Wikipedia contexts [1]. Wanner et al. showed that factuality evaluation is
sensitive to decomposition and studied coverage, coherence, and atomicity [2].
FactLens provides a newer benchmark and evaluators for fine-grained claim
verification, emphasizing context preservation and semantic equivalence [3].
Hu et al. demonstrated that decomposition can add downstream noise as well as
benefit [4]. VeriGraph operationalizes these concerns in an interactive audit
surface, while connecting each model output to a deterministic argument and
verdict trace.
